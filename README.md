# 🪢Tangler

Generate testable dirty data for entity resolution.

## Contributing

Environments and depenencies are managed with [uv](https://docs.astral.sh/uv/).

Task running is done with [just](https://just.systems/man/en/). Get started:

```bash
just
```

[Pre-commit hooks](https://pre-commit.com/) are in use and should be installed:

```bash
pre-commit install
```
